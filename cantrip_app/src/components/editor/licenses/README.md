# License comparison fixtures

Canonical license text from SPDX license-list-data, commit 31ba1a50e5397e00a304dbadc76531740e89ee48:
https://github.com/spdx/license-list-data/tree/31ba1a50e5397e00a304dbadc76531740e89ee48/text

These texts are test fixtures only and are not bundled into the client. The client lazily loads descriptions and SHA-256 fingerprints of the complete normalized texts. Leading copyright placeholders, whitespace and known short headings are normalized; modified clauses, incomplete excerpts, dual-license documents and extra terms do not match. The full original file always stays visible.

Descriptions are written for Cantrip and checked against the linked Choose a License references in license-catalog.ts. GPL version text alone does not establish an “or later” option for a project.

Trailing whitespace from the source texts is trimmed; the license wording is unchanged.
