# Provider logos

These assets identify the services and projects in the Add provider menu. The
marks belong to their respective owners.

- [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/05260484d9f4de68f90cc87a634ae68fa4043efd/packages/static-svg/icons)
  supplies the monochrome Grok, OpenAI, Unsloth, xAI, and Z.ai glyphs. See
  [its MIT license](LobeHub-LICENSE.txt).
- [ggml-org's llama.brand](https://github.com/ggml-org/llama-brand/tree/9e91eb167731ae69a3f2108b3b577b6baf32dede)
  supplies the light and dark llama.cpp glyphs. The assets are CC BY-NC 4.0
  with [explicit permission for software distributions](https://github.com/ggml-org/llama-brand/blob/9e91eb167731ae69a3f2108b3b577b6baf32dede/BRAND-USAGE.md).
- The [LiteLLM brand kit](https://www.litellm.ai/brand-assets) supplies the blue
  and white monograms, mirrored from
  [its docs repository](https://github.com/BerriAI/litellm-docs/tree/e8ac7e3928ea4a614ae2ab0293893638dd8e94ff/static/img/brand).
- [Apple's MLX repository](https://github.com/ml-explore/mlx/tree/0b8f853ff8f2dd8cc3715162c8c332eeffcbef7b/docs/logo)
  supplies the light and dark MLX wordmarks. See [its MIT license](MLX-LICENSE.txt).
