merge is established by GitHub after publication, not predicted here.

## Actual release artifact result

The cycle 15 worktree ran the real `pnpm package:app --target darwin-arm64` with
the available Developer ID identity and `CANTRIP_REQUIRE_MACOS_SIGNING=1`.
It built bundled Codex 0.153.4, worker/runtime and the optimized Tauri app, signed
the nested runtime before the enclosing app, and emitted Cantrip 1.1.1810 app,
DMG and updater archive. It then exited 1 because `TAURI_SIGNING_PRIVATE_KEY`
was absent. Tauri separately reported missing Apple notarization credentials.
No synthetic build, replacement updater key, ad-hoc fallback or release upload
was used.

Running the existing `verify-macos-distribution.mjs` against those emitted
artifacts passed: one certificate-signed app, one signed DMG and 28 embedded
runtime binaries, including actual CUA handshake/fake snapshots and packaged
Sharp encoding. The helper inside that exact `.app` then passed the six-scenario
native fixture, including complete occlusion, resize and recreation. This proves
the actual bundled executable works; it does not make the failed overall package
command or unperformed updater/notarization checks green.

Required release follow-up: supply the project's real updater signing private
key through its normal private release environment, and supply the existing
Apple notarization credentials. Rerun the normal packaging/notarization workflow,
then test a real installed signed update and record its capture permission
behavior. No release was published and the installed Cantrip app was untouched.
The goal explicitly permits documenting unavailable signing credentials and the
exact unverified manual step; these remain release qualifications, not fabricated
native verification.

## Results that must not be overstated

- Local full protocol: 666 tests. Final-head compiled CUA boundary: 1,252 tests
  on each macOS/Windows/Linux CI host, with three explicit server skips; the two
  PostgreSQL cases pass in their dedicated job, and native tests run separately.
- Relevant app/worker/server builds pass. `pnpm check` still stops at existing
  server decomposition counts 2,156/2,149 versus 1,999, before later chained
  checks. Existing unrelated regression failures remain identified in the ledger.
- Native validation was on macOS arm64. Windows/Linux results exercise the
  portable runtime and explicit fake capture, not native desktop backends.
- Native Retina hardware, physical mobile devices, minimized/hidden/other-Space
  or protected surfaces, notarized installation and an actual app update were
  not verified. Native errors are reported rather than bypassed or replayed.
- Logical movement does not inject input. Accessibility, clipboard/files,
  human-input events, continuous video, other native backends and cross-worker
  control remain outside this tranche. The full CUA roadmap remains unfinished.
