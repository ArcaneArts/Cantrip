# Project and captured Run state contracts

Rust remains the default server. This milestone qualifies thirteen active
repository identities and records two obsolete-helper dispositions. It repairs
captured Run validation, its public error handling and macOS PostgreSQL asset
repackaging. Complete replacement acceptance remains open. The base is
`e097e25cb6aa9da250c47e0929e10b695668f490`.

## Captured Run behavior

The retained paired baseline shows Source rejecting unknown fields in stored
Cantrip OS Run roots while Rust returns the unchecked object. Native capture reads
now apply the existing strict `cantripOsRunRootsSchema`, after constructing the
runtime summary in the same evaluation order as Source. Valid worker and OS
captures retain their current projections, ownership and execution identity.

The real public caller exposed a second mismatch: Source returns its HTTP 502
validation response, while native middleware returned generic HTTP 500. Capture
read failures now retain the Run API error contract through status, output and
lifecycle requests. OS-source selection preserves those read failures instead of
reclassifying them as target conflicts. Genuine missing/non-OS target selections
still return the existing HTTP 409 conflict.

Actual relation removal also exposed different SQL error bodies. The native
reader now attaches the current generated Source statement and parameters only
after a real query fails, using the existing query-error adapter. It adds no
preflight query or startup gate. The generator invokes the actual reference
repository with a query-capturing driver; the HTTP comparison independently checks
its SQL and each peer's real owner/runtime parameters before aliasing the owner
for comparison. Raw diagnostics remain in the reports.

them before resolving dependencies. The final package retains all fifteen supplied
distribution notices.

migration/export launchers and shutdown with Node absent from the server PATH,

verified. Executable size and SHA-256 are recorded in the evidence summary.

current native authority checks, sixteen schema graphs plus the endpoint-provider

worker/app baseline failures retain their scope in
[Node retirement](RUST_SERVER_NODE_RETIREMENT.md). No hosted Actions are used.

Current Windows/Linux shipping artifacts, final integrated upgrades/post-write
